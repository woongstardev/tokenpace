# tokenpace

Feel what "tokens per second" actually means — **in your own language, against your own reading speed.**

Most tok/s visualizers are English-only, ignore time-to-first-token, and give you no reference point.
tokenpace adds all three: per-language token density, a TTFT delay, and a reading-speed baseline.
